Variables

Detected automatically — check and adjust. Repeated measures (same name, different timepoints) are analysed as one outcome with one table. Single variables sharing the same Table name appear together in one table.

Distribution: Auto uses Shapiro-Wilk in every group — a single variable is non-parametric if any group fails; a repeated outcome if more than 25% of group × timepoint cells fail. The chip shows the result. Levels: order of categories, comma-separated (the first is used for relative risk).
