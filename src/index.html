2 · Groups

Choose the column that defines the study groups, or analyse all patients as one group. Labels are used in tables, figures and comments.

One group: tables describe all patients; repeated measures are compared over time within the same patients (paired t-test / Wilcoxon, repeated-measures ANOVA / Friedman).

Use ↑/↓ to set the column order of groups in tables.

Variables

Detected automatically — check and adjust. Repeated measures (same name, different timepoints) are analysed as one outcome with one table. Single variables sharing the same Table name appear together in one table.

Categorise

Distribution: Auto uses the normality test chosen in step 3 (Shapiro-Wilk by default) in every group — a single variable is non-parametric if any group fails; a repeated outcome if more than 25% of group × timepoint cells fail. The chip shows the result. Levels: order of categories, comma-separated (the first is used for relative risk / odds ratio).

Subgroup analysis

E.g. the comparison of the groups separately in men and women. Each subgroup gets its own tables (titled “… — Sex: Male”), figures and comments in the report. Choosing the group variable gives the tables of each group on its own (a description of the patients of that group).

Calculated variables

Create a new column from existing ones, e.g. BMI from weight and height, a change score, a total score or BMI classes. The column is added to the sheet (undo with ↶ in step 1) and to the variables above.

Repeated measures

Detected from column names with timepoints (e.g. VAS_baseline, VAS_W1). Create your own from any numeric columns, edit which columns enter and their timepoint labels and order, or ungroup a measure back into single variables. In the table above you can also untick single timepoints or analyse a measure as separate variables.
