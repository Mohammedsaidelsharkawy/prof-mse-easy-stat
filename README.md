# Prof MSE Easy Stat

An offline web app that turns an Excel mastersheet into a formatted Word statistical report: methods paragraph, CONSORT flowchart, results tables, auto-written comments and figures.

## Using it

1. Download `Prof_MSE_Easy_Stat.html` and open it in a modern browser (Chrome, Edge, Firefox). No installation or internet connection is needed.
2. Follow the 11-step wizard. **＋ New**, **📂 Open project** and **💾 Save project** (top right) start a new project, or save and reopen everything in one file: the data with your edits, every setting and the text edited in step 10.
   1. **Upload** the Excel file (or open an example) and enter the study title. The software statement, the first sentence of the Statistical Analysis section, can be picked from templates (IBM SPSS Statistics — the default, Prof MSE Easy Stat, R, Stata, GraphPad Prism, SAS, MedCalc, JASP, jamovi, Python, Minitab, Epi Info, Excel). **📋 Paste from Excel** (copied cells, tab- or comma-separated) or start from a **blank template** (with a guide sheet). The column names are found by themselves: title rows above them are skipped and a title merged over several columns (VAS over Baseline / W1 / M3) gives VAS_Baseline, VAS_W1 …; both can be changed under **Prepare the data**, which also blanks **missing-value codes** (999, -99, NA, .), **analyses only some patients** (conditions such as Age ≥ 18 and Centre = A — the sheet keeps every row and the Statistical Analysis section says so), and **adds data from another file** (more patients matched by column name, or more variables matched by ID). An overview line shows the patients, column types, % missing cells, duplicate IDs, empty and one-value columns and the filter. **🏷 Recode values** renames, merges or blanks the categories of a column (M, male → Male; Y → Yes), with one-click capitalising; **⇄ Long to wide** turns one row per visit into one row per patient (HbA1c_Baseline, HbA1c_Month 3 …); data from another file can also come from **another sheet of the same workbook**. The **🩺 data check** now also finds and fixes numbers typed with units (“54 years”, “82 kg”), words and codes used for missing values (NA, -, ., 999, -9, a 9 among 1/2 codes), rows entered twice and empty columns, and flags impossible values for age, BMI, blood pressure, heart rate, VAS, FEV1, HbA1c, weight, height and percentages; columns that become numbers after cleaning are grouped into repeated measures again. Column names such as “Month 3”, “Week 12” or “6 months” are read as timepoints. The data grid has striped rows by default and can highlight outliers (beyond 1.5 × IQR of their column). **✂ Split column** splits values at a separator into new columns (blood pressure 120/80 → SBP and DBP, “3x4” sizes, dash-separated codes), with a preview. **↓ Fill down** copies each value into the empty cells below it (a group name or merged cell written once per block). **✨ Tidy column names** trims spaces, joins words with “_”, removes line breaks and odd symbols and makes every name unique, with the setup following the new names. **More import**: SPSS files (.sav, including compressed and .zsav) come in with their variable labels, value labels (as value labels and group names), user-missing values and dates; CSV / text files open with a preview and a choice of text encoding (UTF-8, Arabic Windows-1256, Western, UTF-16), separator and decimal mark; **Stack all sheets** puts every sheet of a workbook one under another with the sheet name in a column. **Checking**: rules for plausible values (a column against another column, a number or a range, with presets such as DBP < SBP, discharge ≥ admission and age 0–120; dates compare as dates), duplicates on chosen columns with near matches (case, spaces, one typing error — never different numbers), a missing-data map with Little's MCAR test (EM estimates; matches R's naniar), deleting rows that miss more than a chosen share of their cells, and Yes/No written as Y/N, +/−, true/false or positive/negative. **Dates**: Excel day numbers and typed dates (day/month/year, month/day/year or year-month-day) become yyyy-mm-dd, and a new column can hold the time between two dates in days, weeks, months or years (e.g. age from the date of birth). **The grid**: a menu on every column (its chart and statistics, sorting, and a filter of the rows shown), column widths by dragging, a header row that stays in view, pasting a block of cells copied from Excel and Ctrl+D for the value above, and a **📝 Form** to type or check one patient at a time. **Safety**: anonymising (names, phones and file numbers replaced by codes P001 … or deleted), a random sample of N patients for a pilot report (seeded; the methods say so), named snapshots, a **cleaning log** of every change (what changed and how many cells) saved with the project and exportable to Excel, and **⬇ CSV** of the cleaned data.
      **Messy datasets to practise data cleaning**: a hypertension clinic list (beginner), an asthma trial with two header rows (intermediate), diabetes visits in long format with a second sheet (advanced) and SPSS-style coded data with a codebook (intermediate). Each opens with a checklist of problems that ticks itself as you fix them, with a hint naming the tool for each, and can be downloaded as Excel.
      The data preview has rows per page with paging, search, a filter for rows with missing values, highlighted missing cells, a column summary (type, range, missing), sorting by any column, row density (compact / normal / comfortable), a column chooser (show all, numeric or text columns), column-type badges with right-aligned numbers, wrapped text, a frozen first column and striped rows. **🩺 Check data** lists duplicate IDs, text in numeric columns, categories written in different ways ("male" / "Male "), extra spaces, empty or constant columns and extreme values (> 4 SD), with one-click fixes; **🔍 Find & replace** works on one column or all, whole cells or parts, with undo. **✎ Edit sheet** lets you change cells, rename, move or delete columns, add columns and rows, move or delete rows, undo, re-detect the variables, and download the edited sheet as Excel; the variable setup follows the edits.
   2. **Variables**: **Value labels** name coded categories (e.g. `1=Male, 2=Female` or `1: Yes; 0: No`): tables, comments, figures, the results by variable and the advanced analyses show the labels while the sheet keeps its codes. **Calculated variables** add new columns: BMI from weight and height (also at every timepoint of a repeated weight), change (B − A), % change, ratio, total or mean score, logarithm, categories from cut-offs (e.g. WHO BMI classes) or your own formula with [column] names. Choose where the column goes (after its source column, at the start or end, or after any column) and which report table shows it. Confirm the group variable, outcomes and baseline characteristics; create, edit or ungroup repeated measures. Bulk buttons include or exclude all (or only numeric / categorical) variables and set the distribution of every numeric variable. Choose **One group — all patients together** when there are no study groups: tables then describe all patients (mean ± SD / median (IQR), n (%)), with histograms and percentage bar charts, and repeated measures of the same patients are compared over time (paired t-test or Wilcoxon signed-rank test for two timepoints; repeated-measures ANOVA or Friedman test with Bonferroni-adjusted comparisons against the first timepoint for more), with the change from the first measurement and its 95% CI. Kaplan-Meier gives a single curve, and the flowchart defaults to STROBE. A search box finds a variable in long lists. **⬇ Codebook (Excel)** lists every column with its label, role, type, timepoint, table, categories with counts, value labels, n, missing values, mean ± SD, median (IQR) and range — ready for a thesis appendix. All labels can be set in sentence case, Title Case or made again from the column names. **Only included** hides the variables left out. **⚙ per variable**: unit (added to the label), decimal places, role (baseline characteristics read “the groups were comparable regarding …”), **ordinal** type with the Mann-Whitney / Kruskal-Wallis test on the category order (Dunn post hoc) or the Chi-square test for trend (linear-by-linear association), a log / log₁₀ / square-root transformation, the category shown in one-row (yes/no) variables, merging or renaming categories at analysis time, an Arabic label, a private note (ℹ in later steps) and an adjusted comparison (ANCOVA) added to step 8. **The list**: drag ⋮⋮ to reorder (the order of the tables), select variables to set their table or type or copy the settings of another variable, warning badges (more than 20% missing, a group with fewer than 5, many categories, sparse expected counts), ⚡ auto-assign tables by the variable names, a new column of median-split groups, tertiles or quartiles, and the setup as CSV to edit in Excel and read back. **Groups**: merge one group into another and choose the control group. **Subgroup analysis** repeats every table within each category of a column (e.g. men and women), with or without the tables of all patients. Labels can be printed in Arabic or in both languages, and known abbreviations (BMI, CRP, ASA …) can explain themselves in the footnotes.
   3. **Timepoints**: each repeated outcome has its own timepoints — tick which enter, rename them and set their order per outcome. **⇅ Sort in time order** (baseline first, then by number and unit — minutes, hours, days, weeks, months, years — post / final last) and **Aa Readable labels** (M3 → Month 3, W1 → Week 1, 24h → 24 h). **First & last only** keeps each outcome's first and last timepoint (e.g. before and after); **All** brings every timepoint back. **Time**: each timepoint can have a time value (e.g. hours) — line charts then place the timepoints at their real time, and the area under the curve, the mixed model and the trend test use it — and a phase shown before its label (Intra-operative: 30 min); label templates (T0 …, Before / After, Pre-op / Intra-op / Post-op / Day n, Baseline / Visit n, Baseline / Month n) and ⇅ Reverse. **Per outcome**: the reference timepoint of the change, the primary endpoint (its row in bold, named in the footnote), responders (a fall or rise of at least X% from the reference, n (%) per group with the Chi-square / Fisher test at each timepoint) and copying these settings to the other outcomes. **Analysis over time**: a linear mixed model (group, time and group × time, a random intercept per patient, REML, every available measurement; matches statsmodels), a linear trend test within each group, and last observation carried forward for missing follow-up values. **Tools**: derived outcomes as new columns (area under the curve, peak, lowest value, time of the peak, mean over time, last − first, time to reach a value), merging two timepoints written two ways, an outcome × timepoint grid with a warning when the outcomes use different timepoints, missing values per timepoint and group, and every patient over time (spaghetti chart). Repeated yes/no outcomes are analysed with Cochran's Q in step 8, and **⇄ Long to wide** accepts visit windows (0=Baseline; 25-35=Month 1).
   4. **Tests**: significance level, normality test, effect estimates, post hoc and optional tests, Bonferroni or Holm adjustment of pairwise Mann-Whitney and categorical comparisons. After a significant Kruskal-Wallis test, Dunn's test (Bonferroni) is the default post hoc test. With 3 or more groups, categorical variables get pairwise Chi-square / Fisher tests between each two groups (Bonferroni) by default. The pairwise categorical comparisons can be Bonferroni-adjusted, Holm-adjusted or uncorrected; the comments, footnotes and statistical analysis text follow. **Repeated measures**: post hoc comparisons over time (against the first timepoint, consecutive timepoints or all pairs), Bonferroni, Holm or no adjustment, Greenhouse-Geisser, Huynh-Feldt or no sphericity correction, post hoc tests even when the overall test is not significant, the groups compared on the change (or % change) from the first timepoint and on each patient's area under the curve, and individual patient lines on line charts. A **test plan** lists, for every variable, its distribution, the test between the groups, the post hoc test used when it is significant and the P value — updated as the settings change. The test plan can be saved to Excel. **More test options**: confidence level of every interval (90 / 95 / 99%), one-sided hypotheses for two groups, a Benjamini-Hochberg false discovery rate across the report's between-group P values, the large-sample rule (parametric when every group has n ≥ 30), the exact Mann-Whitney P for small samples (permutation when tied), bootstrap CIs of the median difference, the Fisher-Freeman-Halton exact test for larger tables, a **P for trend** column across ordered groups (Jonckheere-Terpstra / Cochran-Armitage / linear-by-linear), complete cases only, skewness and kurtosis z-scores as the normality test, and Hedges g, Glass Δ or Cliff's δ in the effect-size comments. Each variable's ⚙ window can force its test (t, Welch, ANOVA, Welch ANOVA, Mann-Whitney, Kruskal-Wallis, Chi-square, Fisher, Fisher-Freeman-Halton). The test plan (exportable to Excel) shows the normality P of each group, Levene's test, Mauchly's test of sphericity (pooled within-group covariance, as SPSS) and flags variables whose parametric and non-parametric tests disagree. A **sample size calculator** (two means or two proportions, power, allocation ratio, drop-out) helps plan a new study. Step 8 adds equivalence testing (TOST), Mantel-Haenszel stratified odds ratios with the Breslow-Day test, and conditional logistic regression for matched sets; step 10 adds Yuen's trimmed-means test, the JZS Bayes factor, Hedges g / Glass Δ / Cliff's δ, the Brown-Forsythe test of means and the Jonckheere-Terpstra trend test.
   5. **Tables**: counts in categorical rows as 19 (63.3%), 19 (63.3), 19/30 (63.3%) or 63.3% (19); Word table text size (8–12 pt), header colour (grey, lavender, light blue, light green, navy with white text, or none), cell spacing, banded rows per variable and left-aligned variable names (also shown in the preview); number formats, second row (range / 95% CI / IQR / none), P value decimals, heading and mark, test-statistic column, missing-data note, the tests used named in the footnote (listed, or as letters after each P value: 0.013ᵃ), a Total column, group sizes in the headings, bold significant P values, each table on a new page, P values with or without the leading zero (.013), table style, font, page orientation, caption style. Table captions are justified by default (or centred / left). A **design preview** shows a real table from your data — caption, table, footnote and comment — as it will look in the Word file, redrawn as each option changes. Tables can take the full page width or 90% / 75% of it. **Word page**: A4, US Letter, B5, A5 or US Legal, normal / narrow / wide margins, single to double line spacing, page numbers centred, right, “Page 3 of 12” or none, a running header, and a list of tables and figures at the start. An extra footnote line (e.g. the data source) can close every table footnote. **Layout**: journal-style categorical rows (the name on its own row, categories indented), a Total row under each categorical variable, “n” and “Missing” columns, mean ± SD and median (IQR) together, one row only for chosen variables (step 2 ⚙), the effect column limited to mean/median differences or to RR/OR, post hoc results as compact letters (a, b, c) after the group values, no P values in the baseline table of a randomised trial (CONSORT; the comment then only describes), your own headings and order for the group columns, significant P values in colour, a separate table font, numbers aligned on the decimal point in Word, long tables split every 25 or 40 rows with “Table 3 (continued)”, and portrait pages with landscape pages only for wide tables. **Tools**: merge one table into another, and save the step's settings as named table styles to reuse. In step 11 each table can be saved alone as a Word file or a PNG picture; chapter numbering such as Table 4.2.1 is the thesis chapter field (type 4.2).
   6. **Comments**: the size of each significant effect (Cohen's d, r, η², ε² or Cramér's V, labelled small / medium / large); concise, detailed or descriptive (every group's values, the test with its statistic, the effect size and a closing overview of each table), P value wording, placement (after / before the table / none), effect sizes, summary of key findings. A **comment preview** shows the comment written for a table of your own data, with its word count, as the options change. **More**: presets (thesis, journal, plain language), a plain-language tone, varied wording so phrases don't repeat, “a non-significant trend” for P between the significance level and 0.10, non-significant two-group results with their difference or RR/OR and 95% CI, the minimal clinically important difference of a variable (step 2 ⚙) checked against a significant difference, effect size labels by Cohen, Sawilowsky or Ferguson, sentence templates with placeholders ({variable}, {P}, {highest} …), a phrase dictionary applied to every comment, word limits for each comment and for the abstract results, numbered key findings under each table, figure references “(Figure 3)”, significant findings in bold and one combined results paragraph in Word. In step 11 each comment has ⧉ Copy, a spelling check and ℹ Explain (plain meanings of the statistical terms), and **✓ Check comments** lists numbers that are not in the table and causal wording.
   7. **Figures**: significance as stars, exact P values or both; groups told apart by colour or by colour plus marker shapes and line patterns (for greyscale print); line weight; error bars with or without caps or upward only; gridline style (solid, dashed, dotted, darker); fewer or more axis ticks; chart types per variable with live preview, colours, legend, error bars, bar width, mean markers, chart font, a y-axis range and a labelled reference line for each variable, a frame around each figure, an export of the previewed figure (PNG, JPEG or TIFF), chart types per variable (bars, box, violin, dot, mean with 95% CI, histogram; horizontal bars, 100% stacked, donut or pie), placement and captions. Captions explain the symbols: what *, ** and *** mean, what the bars, error bars, boxes, whiskers and markers show. A **design preview** shows the current chart style on four kinds of figure (bars between groups with a significance bracket, lines over time, box plots, 100% stacked bars), redrawn as each option changes. Error bars in black or in the colour of each group. **⧉ Copy** puts the previewed figure (and the flowchart in step 9) on the clipboard, to paste into Word or PowerPoint. **Chart for all** sets one chart type for every numeric, categorical or repeated variable at once. **More**: raincloud plots, every patient with the mean and 95% CI, mosaic plots (bar widths = group sizes), waterfall plots of each patient's change (repeated outcomes), swimmer plots (step 8 survival), a correlation heat map, a forest plot of the standardized differences of every variable (two groups; binary variables converted from the log OR), significance letters (a, b, c) instead of brackets, a log scale and its own shape (wide, 4:3, square, tall) per figure, panel styles (classic, minimal, grey background), sizes of the axis numbers, axis titles and value labels, the mean written beside each box, colour pickers named after the groups, hover values in the preview, multi-panel figures (A, B, C) and captions above the figures in Word. The figure export adds **SVG** (vector) and a journal text size (8 or 10 pt at the chosen width).

Analyses can be moved up and down. **More analyses**: Poisson / negative binomial regression (incidence rate ratios), ordinal (proportional odds) and multinomial logistic regression, Passing-Bablok and Deming method comparison, principal component analysis with varimax rotation (KMO, Bartlett's test, scree plot), partial correlation, two-way ANOVA (group × a second factor, type II), mediation (Sobel test and bootstrap CI of the indirect effect), propensity-score matching (1:1, caliper) and weighting with balance (SMD) tables, and a linear mixed model of a repeated outcome adjusted for covariates. **Autosave**: your work is kept in this browser as you go; on the next visit a bar in step 1 offers to continue where you left off (🆕 New clears it). **Shortcuts** (⌨ Shortcuts or ? lists them): Ctrl/⌘+S save and Ctrl/⌘+O open a project, Ctrl/⌘+Z undo and Ctrl/⌘+Y (or Ctrl/⌘+Shift+Z) redo a data change — also with the ↶ Undo / ↷ Redo buttons of steps 1 and 10, Alt+→ / Alt+← or ] / [ next and previous step, 1–9 and 0 go to steps 1–10, R the report, / search on the step, T theme, and on the steps C check data, E edit the sheet, F export figures, W Word, X Excel and V the next view of step 10. **↺ Defaults for this step** (steps 4–7) sets every option of that step back to its default.

`Sample report.docx` is example output generated from simulated data.

## Statistics

- Normality: Shapiro–Wilk, or Kolmogorov–Smirnov with Lilliefors correction
- Between groups: independent t-test, Mann–Whitney U, one-way ANOVA (Tukey), Kruskal–Wallis, Chi-square, Fisher's exact
- Optional: Welch's ANOVA with Games-Howell post hoc for unequal variances, Dunn's post hoc after Kruskal–Wallis, pairwise Chi-square / Fisher post hoc (Bonferroni) for categorical variables, group × time interaction by mixed (split-plot) ANOVA
- Within subjects: paired t-test and Wilcoxon signed-rank (two timepoints); repeated-measures ANOVA (Greenhouse–Geisser) and Friedman test (three or more), with Bonferroni-adjusted post hoc comparisons against the first timepoint
- Correlation (optional): Pearson or Spearman between numeric variables, with scatter plots of significant pairs
- Effect sizes and 95% confidence intervals
- Advanced (optional): multiple linear regression (B, β, 95% CI, R²), binary logistic regression (univariable and multivariable OR, Nagelkerke R²), ROC curves (AUC with DeLong 95% CI, Youden cut-off, sensitivity, specificity, PPV, NPV), ANCOVA (adjusted means and Bonferroni pairwise comparisons), Kaplan-Meier survival with the log-rank test, Cox regression (hazard ratios), McNemar / McNemar-Bowker for paired categorical data, Cohen's kappa, ICC with Bland-Altman analysis, diagnostic accuracy from a 2×2 table (sensitivity, specificity, PPV, NPV, likelihood ratios, exact CIs), Cronbach's alpha
- Binary variables: relative risk or odds ratio
- Stage 4 additions, checked against Python: TOST (statsmodels ttost_ind), Mantel-Haenszel OR, CI and Breslow-Day (statsmodels StratifiedTable), conditional logistic regression (statsmodels ConditionalLogit), Yuen (SciPy trimmed t-test), exact Mann-Whitney (SciPy), Cochran-Armitage (R prop.trend.test), JZS Bayes factor and effect sizes (pingouin), sample size for two means (statsmodels)
- Stage 8 additions, checked against Python: Poisson, ordinal and multinomial models, LMM with covariates (statsmodels), negative binomial coefficients (statsmodels; SEs at fixed α as R glm.nb), Deming slope, PCA eigenvalues, KMO and Bartlett (numpy), partial correlation (pingouin), two-way ANOVA type II (statsmodels), mediation paths (OLS), NRI, IDI and AUC (sklearn)

The original engine's output (1,808 test values) was checked against R 4.6.1. The paired, Wilcoxon signed-rank and correlation tests were checked against SciPy 1.18 on 300 random datasets. Linear and logistic regression were checked against statsmodels 0.15, and ROC results against scikit-learn 1.9, on 200 random datasets. Welch's ANOVA, Games-Howell, mixed ANOVA and ANCOVA were checked against pingouin 0.7, Dunn's test against scikit-posthocs, pairwise Chi-square against SciPy, and Kaplan-Meier / log-rank against lifelines 0.30, on 120 random datasets. Median survival follows SPSS: the first time survival falls to 50% or below. Lilliefors, McNemar(-Bowker), Cohen's kappa, odds ratios and Clopper-Pearson CIs were checked against statsmodels, ICC and Cronbach's alpha against pingouin, and Cox regression (Efron ties) against lifelines, on 150 random datasets. Weighted kappa matches statsmodels, Kendall's tau-b SciPy, ICC(C,1) / ICC(C,k) pingouin, Kaplan-Meier 95% CIs lifelines, Durbin-Watson statsmodels, Huynh-Feldt epsilon pingouin, Holm statsmodels, and skewness / kurtosis SciPy. The ROC cut-offs by sensitivity / specificity target, the DeLong comparison of two AUCs and the Clopper-Pearson CIs were checked against scikit-learn, statsmodels and a reference DeLong implementation on 200 random datasets.

## Report options

- Comment style: concise, or detailed (quotes group values and every P value); optional "not significantly" wording
- Word tables: grid or three-line academic (APA) style; choice of body font; optional Prof MSE branding in the header (off by default)
- Chart colours: 39 ready themes — Office-style colour sets (Office, Office 2013 - 2022, Office 2007 - 2010, Blue Warm, Blue, Green, Orange, Red, Violet, Paper, Marquee, Slipstream, Aspect and more) and scientific themes (Prof MSE, Classic Office, grayscale, NEJM, Lancet, Nature, JAMA, colour-blind safe Okabe-Ito, Viridis, pastel, ocean, sunset, forest, earth, berry, monochrome blue) or custom colours, chosen from a list of colour strips with a live sample chart of the theme under the pointer
- Chart appearance: text size, shape (wide, 4:3, square), bar fill (gradient, solid, outline, hatched), gridlines, axis arrows, legend position, y axis from zero or fitted, group sizes on axes, high-resolution images, custom colours
- Figures: all, significant results only, or none; error bars as SD, SEM or 95% CI; size and one or two per row in Word; value labels on bars; significance brackets and stars; optional individual data points on box plots
- Figures by variable: choose each variable's chart (bar, box, dot plot with every patient, line, histogram, 100% stacked bar, donut, or none) and caption, with a live preview in step 3
- Figure placement: after each table, all at the end, or at the end grouped by chart type; caption style "Figure 1:", "Figure 1." or "Fig. 1."; optional title on each chart; captions editable in step 5
- Legend: bottom, top, right, inside the plot or hidden; text size, title and frame
- Repeated measures: create a repeated measure from any numeric columns, edit its columns, timepoint labels and order, or ungroup it into single variables; choose the timepoints per outcome, include/exclude and reorder timepoints globally, or analyse an outcome's timepoints as separate variables
- Export: tick which sections, tables and figures go into the Word file (numbering follows); the choice is saved with the setup
- Light and dark theme for the app
